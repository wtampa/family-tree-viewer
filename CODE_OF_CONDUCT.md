# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

We are committed to making participation free of harassment. The full text of the covenant, including the enforcement ladder, is at the link above.

## Reporting

Open a GitHub issue, or if the report should stay private, use GitHub's private vulnerability reporting (see [SECURITY.md](SECURITY.md)). Include what happened and where. Do not include a private family tree, living people's names, or screenshots of a real tree.
