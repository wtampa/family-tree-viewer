# Fan GEDCOM demos

The Simpsons, Duck family, and Harry Potter GEDCOMs ship in this repository. There is no separate download.

| File | Tree |
| --- | --- |
| `sample/simpsons/Simpsons.ged` | The Simpsons |
| `sample/ducktales/DuckTales.ged` | Don Rosa duck family |
| `sample/harry-potter/HarryPotter.ged` | Potter, Weasley, and Black lines |

Each folder also has `portraits.json` (wiki URLs only). `npm run fetch-portraits` downloads the pictures onto your machine. Those image files stay gitignored.

The Westeros kings GEDCOM is fetched from its GenoPro URL by `npm run fetch-samples` and is not committed.

These files are demos, not a genealogical authority, and not a product of Fox, Disney, Warner Bros., or HBO.
